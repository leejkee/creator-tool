# 资源与复用需求

本文定义本地图片、字体、图片处理和可复用模块资源。文档身份与文件生命周期见[文档与文件](document.md)，布局和绘制参数见[渲染](rendering.md)。

## 本地图片

- 普通图片和图片背景统一使用 `assetPath`。素材由用户准备，应用不搜索、下载或通过别名猜测素材。
- `assetPath` 为本地文件路径字符串；相对路径以图片 JSON 文件所在目录为基准，也接受绝对本地路径。新建基础目录、进程当前目录和资源库目录不能替代此基准。
- 省略、空字符串或纯空白表示未选择图片。其他非字符串、显式 `null`、NUL 字符和 URI 形式非法；不接收 HTTP、data 或 file URI。
- 除判断是否纯空白外，不擅自裁剪路径原值。包含中文、空格和合法本地路径分隔符的文件应能读取。
- 首版仅支持 PNG、JPEG、WebP 和自包含 SVG。其他格式按不支持的素材处理，警告并使用缺图占位图；不因环境恰好能解码而扩展支持范围。
- 根据实际文件内容识别格式，不只依据扩展名。自包含 SVG 不执行脚本或加载外部资源；缺少固有宽高时优先按有效 `viewBox` 比例确定尺寸，完全没有尺寸依据时采用 `300×150px`，不依据它所在模块的尺寸改变处理链输入像素。
- 支持格式中的动画素材只取首帧，不随预览时间改变。不能读取或解码的文件按缺图处理；不为它猜测扩展名或另找同名文件。
- 忽略 EXIF 方向信息，不自动旋转或翻正图片。图片的宽高、处理链及裁剪坐标均基于文件存储的原始像素方向，预览和 PNG 使用相同规则。
- 图片必须可参与像素处理和 PNG 导出，不能出现预览可见、正式编码却因资源来源限制失败的正常成功状态。SVG 不加载外链图片、网络字体等外部依赖。
- 读取、处理和导出不修改源素材。中间结果只服务本次出图，不自动落盘。

旧 `assetId`、`assetQuery`、`assetsDir` 和 `assetAliases` 仅保留数据，不参与新渲染。用户需要显式提供 `assetPath`，不能因为旧数据被成功读写就假定已经找到素材。

## GUI 选择与复制素材

| 情形 | 已确认行为 |
| --- | --- |
| 选择本地素材 | GUI 为图片模块选择素材后，最终使用当前文档目录内的副本，不以原目录文件作为新的长期引用 |
| 保存前 | 在 TS 中记录待复制素材，应用后的预览可读取原图；选择或放弃输入不立即复制文件 |
| 复制时机 | 手动保存或 autosave 时复制，然后将待保存文档中的引用更新为副本路径 |
| 文件重名 | 给新副本自动添加后缀，保留已有文件及已有模块引用，不覆盖它们 |
| 副本位置 | 位于当前文档目录内，避免与文档 JSON 或默认 PNG 输出路径冲突；不要求用户维护素材搜索或别名规则 |
| 复制失败 | 报告具体素材问题，不将该次文档保存报告为成功，保留本地编辑供用户修正或重试 |
| 原文件 | 只读取、复制，不移动或修改原素材 |

此表定义 GUI 新选择素材的工作流，不隐式搬移打开文档时已有的全部素材引用。已有 JSON 的相对及绝对路径仍按本地图片规则读取；模板复制与另存为的引用保持遵循[文档需求](document.md#保存与另存为)。放弃未应用的素材选择后，不将该选择带入保存计划。

## 缺图占位

- 未选择图片、文件不存在、读取失败或解码失败时，使用明确显示“警告：找不到图片”的内置占位图，保留模块尺寸、位置和原始引用，并按渲染需求警告。
- 占位图保持比例、完整显示、水平垂直居中；不沿用原素材的 `fit` 裁剪方式，不改变模块布局。
- 占位图跳过原素材处理链，包括函数查找和运行，不因原图裁剪参数或模糊使提示消失；处理声明自身的结构合法性仍需检查。
- 图片背景沿用相同规则，在所属模块范围内显示占位；未配置背景本身不构成缺图。
- 占位仍遵守模块整体圆角、透明度和最终输出边界，不扩大模块或强制覆盖用户外观。

## 字体

| 项目 | 确定规则 |
| --- | --- |
| 选择参数 | 文字模块的 `style.fontFamily`，作为单个字体家族名使用 |
| 缺省 | `"sans-serif"`，由系统选择默认无衬线字体，不以枚举列表第一项作为默认 |
| 显式值 | 非空、非纯空白字符串；不接受 `null` 或其他类型，不将路径或 CSS 字体表达式解释为字体文件或家族列表 |
| 首版范围 | 只支持已安装字体家族，不加载字体文件，不提供安装、上传字体或字体打包 |
| 指定字体不可用 | 警告，回退 `sans-serif`，允许出图，保留原始名称 |
| 个别字形缺失 | 使用系统逐字回退；系统仍无字形时保留系统缺字符号，不删改原文、不阻止出图 |
| 加粗 | 使用所选家族可用的粗体或系统合成粗体；不另要求粗体文件 |

字体选择器提供当前机器发现的家族及本地化别名，去除空名、去重、排序，允许用户主动刷新。枚举结果仅供选择；实际不可匹配的名称仍按不可用规则处理。字体就绪后再进行文字测量和绘制，预览与导出不得先后使用不同的回退结果。

旧 `fonts.regular/bold` 和 `style.font` 可以作为历史数据保留，但不影响首版渲染；`style.font` 按未知样式参数处理。系统字体和字形回退可能随机器不同，不承诺跨机器逐像素一致；同一环境、同一输入的预览与导出必须一致。

## 图片处理声明

图片模块可以提供 `processors`，省略或空数组表示不处理。其他模块不接受非空处理链，图片背景没有独立处理链。

```json
{
  "processors": [
    ["image-tools.cropRectangle", {"x": 20, "y": 10, "width": 200, "height": 120}],
    ["image-tools.scaleImage", 0.5]
  ]
}
```

- 每步必须为 `[函数标识, ...参数]`。标识是非空、非纯空白字符串，按完整值精确匹配，区分大小写，不裁剪或解析其中的点号。
- 标识对应应用明确提供的 TypeScript 处理入口，不是文件路径、可执行代码或旧 Python 脚本。重复注册标识拒绝，不能覆盖已有入口；未提供的入口不能隐式加载。
- 附加参数按顺序传入，可为任意 JSON 值；`["module.fn"]` 是零个参数，`["module.fn", null]` 是一个实际 `null` 参数，不隐式补空对象。
- 处理时自动把当前图片放在附加参数之前。参数数量、类型和范围由该处理函数约定，处理函数标识不为空不代表参数有效。
- 对正常素材，整条链的声明和入口先确定再运行；任一步入口缺失时不运行前面的步骤。每一步等待完成后才进入下一步，异步步骤也保持数组顺序。
- 输入图像及参数独立于源素材和文档。处理期间外部修改声明或参数不能改变已经开始的链；函数即使就地修改后失败，也不能污染调用方原图或文档。
- 每步必须返回有效、非空、已解码且可继续绘制的图像，下一步使用上一步结果。失败立即终止，不执行后续步骤，不返回部分成功；空链的结果也不能与输入共享可修改像素。
- 单次资源读取、解码、字体加载和异步处理步骤默认等待上限为 30 秒，调用方可提供 `1～2147483647` 的整数毫秒覆盖；超时或取消立即停止等待和后续步骤，不返回部分成功。同步处理函数返回之前不能承诺可抢占，应由提供函数的一方避免无限阻塞。
- 处理完成后才进行模块内的 `fit`、对齐和裁剪。处理参数中的坐标属于当前步骤的输入，不一定是原素材坐标。
- 旧单字段 `processor` 不执行；早期 `{script, function, params}` 对象格式不隐式转换为当前调用数组。

## 基础图片操作

以下为当前内置处理标识及参数契约，每个标识恰好接收一个附加参数。操作返回独立图像，保留透明通道，不修改输入。

| 标识 | 参数及约束 | 结果 |
| --- | --- | --- |
| `image-tools.cropRectangle` | `{x, y, width, height}`；`x/y` 为有限非负坐标，可为小数；宽高为正整数；整个矩形在输入内 | 指定宽高的矩形，不自动修正越界 |
| `image-tools.cropCircle` | `{centerX, centerY, radius}`；圆心为有限非负坐标，半径为有限正数，可为小数；整个圆在输入内 | 边长为直径向上取整的正方形，圆外透明，不缩放圆内内容 |
| `image-tools.scaleImage` | 正有限数 `ratio` | 宽高乘同一比例并四舍五入，最小为 `1px`，使用高质量平滑缩放 |
| `image-tools.blurImage` | `{blurRadius, clearCircle?}`；强度为有限非负数，清晰圆为 `{centerX, centerY, radius}` 且沿用圆形边界约束 | 尺寸不变，整图模糊，或圆内保持原图清晰、圆外模糊 |

圆周恰好触及输入边界允许，任何方向超出都报错。裁剪不通过截断参数掩盖越界，图片操作的参数范围不等同于渲染布局像素的整数约束。

模糊强度以像素表示高斯标准差，不添加白色蒙层、噪点或额外透明度。强度为零时返回独立副本，但仍检查清晰圆。原本不透明的外边缘不应因模糊产生透明边，透明源内容和圆周抗锯齿应正确保留。环境不支持所需模糊能力时明确失败，不能静默返回未模糊图片。

## 全局模板与 Style 资源库

- 模板与 Style 保存到用户本地的全局资源库，跨 workspace 共用；切换工作区后仍可使用同一批资源，资源不混入 workspace 的普通文档列表。
- 资源库管理记录保存名称、资源内容及派生缩略图等信息，整体写入并检查保存基线；模板内容保持完整图片 JSON，Style 内容保持下述模块资源协议。管理记录不是可由普通文档入口打开的图片 JSON；外部 JSON 文件选择仍遵循文档需求中的同目录同名规则。
- 应用预载内置模板和 Style；管理与选择界面区分“内置”和“我的”，支持预览、创建、编辑、复制及用户资源的重命名、删除。
- 内置原件随应用维护；编辑内置资源时保存为用户副本，应用更新不覆盖用户副本。用户创建的资源可以直接编辑和保存。
- 模板制作、保存为模板及创建作品的生命周期见[文档需求](document.md#新建与模板复制)。模板与 Style 均由应用内编辑器制作、修改。
- 当前模块右侧详情提供提取 Style 的入口。从选中模块提取其显式参数及子配方，沿用下述参数管理范围；不携带实际图文、目标 ID、来源笔记等内容数据。编辑器应保留参数“未提供”与显式值的区别，不把预览默认值补入配方。
- 保存、切换、关闭资源时处理未应用输入和未保存编辑；写入失败保留工作副本和原文件，外部文件变化不得静默覆盖本地编辑。资源选择和预览不隐式保存当前作品或修改源资源。
- 从模板创建的作品和应用 Style 后的作品均独立于原资源；修改或删除用户资源不联动已有作品。

## 演示图片与资源预览

- 应用提供统一的 `512×512px` 演示图片，白色背景，中央显示“演示图片”；各处复用同一内置资源。
- 模板允许包含图片模块及图片背景，但制作、编辑和预览时统一使用内置演示图片，不保存或复制源作品的用户图片，也不要求资源库管理用户素材。只替换已知图片内容及背景引用，不改写来源笔记、任意扩展元数据或源作品。
- Style 不携带图片素材或素材路径。从模块提取时不携带图片内容或图片背景的素材绑定；需要预览图片效果时使用内置演示图片。普通作品和实际模块资源的图片能力仍按本地图片规则处理。
- 模板编辑和使用不依赖某个用户模板目录继续存在；演示图片由应用统一提供。使用模板后，作品可正常保存和出图，不引入对模板原件或用户素材库的长期依赖。
- 模板和 Style 在资源选择界面显示缩略预览。内置资源随应用提供对应缩略图，用户资源保存时生成并保存对应的缩小图片，供选择界面直接展示；缩略图长边不超过 `320px`，保留完整画面比例，不用裁剪代替缩放。
- Style 预览通过临时演示模块或文档承载实际图文；这些演示内容、身份、尺寸及渲染默认值不回写 Style。预览和缩略图使用现有共享渲染逻辑，图像是派生结果，不是 Style 的图片素材依赖。
- 缩略图与资源内容版本对应，修改资源后重新生成，不能将旧版本图像显示为新版本的有效预览。预览生成失败时显示明确的不可预览状态和原因；资源是否可读写仍按文档与资源读写规则判断，不把渲染失败自动当作源文件保存失败。缩略图丢失或无法读取时显示占位并允许重新生成，不丢弃资源管理项。

## Style 与模块资源格式

模块资源不同于完整图片 JSON，根部以 `resourceKind` 区分用途：

```json
{
  "resourceKind": "style",
  "module": {
    "type": "text",
    "width": 320,
    "height": 80,
    "style": {"fontSize": 32, "color": "#000000"}
  }
}
```

| 类型 | 内容 |
| --- | --- |
| `resourceKind: "style"` | 不携带目标身份和实际图文的参数配方；最小内容模块配方可用 `module.type` 指定图片、文字或矩形；布局或仅装饰配方省略类型，可有 `layout`、放置记录 `children`、外观及处理参数 |
| `resourceKind: "image"` | 一个有实际内容和 ID 的完整模块，可为文字、图片、矩形或容器；子模块不重复声明 `resourceKind` |

两类资源共用父子放置结构，不给完整图片文档额外添加资源包装。模块资源不能当成缺少文档身份的完整图片直接打开；从完整 JSON 创建文档的模板规则仍由文档需求负责。本轮纳入全局模板与 Style 库；通用模块资源插入工作流仍未纳入本轮交付。

实际模块资源中的相对素材路径仍以资源文件所在目录为基准，转入图片前应明确其指向，不能误用目标 JSON 目录。全局资源库制作的模板及 Style 则遵循上述演示图片规则。

## Style 一次性应用

- 应用是主动编辑，结果保存为目标模块的实际参数，不建立动态来源引用。重新打开、预览或导出不再次套用源 Style；修改源 Style 不改变已有图片，再次应用才更新。
- 仅覆盖配方中显式提供的受管理参数，未提供的参数保留目标原值，不因遗漏而删除，也不把渲染默认值补入配方。对象按显式字段递归覆盖，例如只提供 `style.color` 时保留原字号、字体及其他外观参数；边框和背景等嵌套对象也遵循同一规则。
- 受管理参数中的数组按完整值处理，不按索引合并；`children` 配方的匹配另按下文规则。`processors` 省略时保留旧链，显式提供时替换完整旧链，显式 `[]` 表示清空处理链。合法的 `0`、`false` 等值按实际值覆盖，不视为遗漏。
- 未提供 `style` 或提供空对象不改变已有外观；不将 `null` 当作清除或恢复默认的指令，显式参数的合法性仍由统一渲染规则判断。
- 叶子尺寸没有默认值；配方省略尺寸时保留目标尺寸，目标本身缺少尺寸则仍缺少，不能因应用 Style 自动补出尺寸。无效参数仍可编辑和保存，渲染时报告问题。
- 当前有效的顶层管理参数为 `width`、`height`、`padding`、`gap`、`fit`。旧 `contentScale`、`offsetX/offsetY`、`zIndex`、`rowGap/columnGap` 仅在配方显式提供时覆盖，遗漏时保留，但不因此获得渲染支持。
- 保留目标 `id/type`、实际文字、图片引用、标题、来源笔记、扩展元数据及父子结构；`layout`、子模块数量和位置不随 Style 改变。配方的 `type/layout` 不作为结构替换指令。
- 子配方按直接子模块的 `position` 对应；没有配方的目标子模块保持原样，没有目标的配方不创建模块。配方同一位置重复时以最后一项为准；不另作类型或布局匹配拦截。
- `children` 省略或为空时仅应用当前模块，已有子模块不变。其他未受管理的配方顶层扩展字段不复制给目标。
- 应用操作不预先做渲染业务校验；应用后仍需统一渲染校验。不能因应用成功就宣称可出图，也不能通过应用自动修复非法尺寸或结构。
- 结果作为一次完整编辑提交，保留版本保护。失败不部分提交；没有实际变化不增加版本；不自动保存文件，不修改输入配方或其他图片。
- Style 的来源与选择由资源库界面明确指定，不通过同名或动态子样式引用自动寻找、覆盖或更新来源。

## 资源一致性与验收

一次渲染必须使用一致的素材、字体选择和处理入口，资源读取能力须提供可比较的版本信息。每次新的渲染重新取得资源状态，不能只因路径相同而永久复用旧结果；执行期间发现资源变化时放弃过期结果并提示重试。已完成结果的 PNG 编码只使用该结果的像素，不重新读取素材。具体缓存、失效检查及传输方式不属于需求。

验收覆盖相对/绝对及中文空格路径、普通本地 JSON 复制和另存后的引用保持、缺图占位及跳过处理链、字体名称不可用与混合字形、图片裁剪边界和透明度、处理参数与顺序、异步失败隔离、资源变化重渲染、Style 按显式字段覆盖且保留遗漏字段及内容/ID、嵌套对象的部分覆盖、处理链省略与显式空数组的区别、未匹配子配方、源 Style 修改后图片独立，以及源素材始终未被覆盖。涉及真实素材时使用工作区副本，不改用户全局配置。

GUI 素材流程还需验证：保存前通过原图预览且未产生复制文件、手动保存和 autosave 的复制与引用更新、重名新副本不破坏已有文件、复制失败保留未保存状态，以及副本与默认 PNG 输出互不覆盖。此处只定义待执行验收，不代表已经实现或验证。

全局资源库还需覆盖：跨 workspace 共用、内置编辑生成用户副本及更新隔离、右侧提取 Style 不修改源模块、模板仅使用内置演示图片且不收集用户素材、Style 中不混入图片绑定或演示内容、选择时显示版本对应的缩略图，以及预览失败或缓存缺失时仍可管理资源。以上是待执行验收条件，不代表功能已经完成。
