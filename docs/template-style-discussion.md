# 模板与 Style 制作功能讨论

状态：本轮核心产品选择已确认，功能已接入实现；桌面交互与渲染验收待用户安排。开发分支为 `feat/template-style-editor`。

本文保留已确认决定与后续实现差异的索引。正式规则按职责纳入[架构](architecture.md)、[文档与文件](document.md)、[资源与复用](resources.md)，本文不维护另一套参数或默认值清单。

## 已确认的功能范围

| 主题 | 决定及规则入口 |
| --- | --- |
| 创建与编辑 | 用户可创建模板和 Style 并保存本地；应用预载部分资源，均通过应用内编辑器使用和编辑。整体入口见[GUI 需求](architecture.md#gui-布局与交互边界) |
| 模板制作 | 采用从空白开始或当前作品另存为模板的方案；任意模块及其子树均可作为完整作品的根，不区分整份作品模板和模块模板。见[新建与模板复制](document.md#新建与模板复制) |
| 提取 Style | 从选中模块提取 Style 的入口放在右侧模块详情。制作、编辑、保存见[全局资源库](resources.md#全局模板与-style-资源库) |
| 资源管理 | 模板与 Style 跨 workspace 全局共用，提供内置与用户资源的管理、选择及预览；编辑内置资源保存为用户副本，更新不覆盖用户修改。见[全局资源库](resources.md#全局模板与-style-资源库) |
| 图片内容 | 模板允许图片，但统一使用应用内置演示图片，不收集用户图片；Style 不携带图片素材，预览使用内置演示内容。见[演示图片与资源预览](resources.md#演示图片与资源预览) |
| 演示图片 | 固定大小、白色背景、居中显示“演示图片”。尺寸及预览规则只在[资源需求](resources.md#演示图片与资源预览)维护 |
| 选择时预览 | 模板和 Style 在选择界面均提供缩略预览，需要保存与内容对应的缩小图片；缩略图是派生预览，不是 Style 的图片素材。见[资源预览](resources.md#演示图片与资源预览) |
| Style 覆盖 | 只覆盖显式提供的字段，未提供字段保持原样，包括嵌套外观字段；一次性应用，不建立动态联动。见[Style 一次性应用](resources.md#style-一次性应用) |
| 编辑保护 | 沿用未保存输入、保存失败保留编辑及外部修改冲突保护；提取资源不改写源作品，应用资源不改写资源原件。见对应文档与资源需求 |

## 实现与验收边界

- 全局资源库、内置与用户资源管理、右侧提取入口及复用画布的资源编辑流程已接入；原有外部 JSON 模板复制入口继续保留。
- GUI 工作副本与独立 Rust Style API 均按显式字段覆盖，区分处理链未提供与显式空数组，并保留嵌套对象中未提供的字段。
- 模板制作使用统一演示图片，Style 不携带用户图片绑定；缩略预览使用共享渲染器和缩放逻辑，资源保存在本地并检查保存基线。
- 实现继续保持 TS 工作副本、Rust 可靠文件操作和共享渲染的职责边界。静态检查、构建与资源生成不代表桌面交互或渲染验收；不新增、修改或运行测试，验收仍由用户安排。
