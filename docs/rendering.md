# 渲染需求

本文是布局、输出、文字、图片外观和渲染诊断的唯一规则来源。文档结构见[文档与文件](document.md)，素材、字体和处理链见[资源与复用](resources.md)。以下规则同时用于预览和 PNG 导出。

模块是否组织子模块由 `layout` 确定，内容类型仅用于最小图片、文本框、矩形模块。本文“容器”表示带 `layout` 的模块，不要求额外类型标记；结构规则统一见[文档需求](document.md)。

## 参数通则

- 必填参数必须存在且类型正确；可选参数仅在省略时使用默认值。非法显式值不得回退为默认值。
- 已定义的渲染参数不接受显式 `null`；合法的 `0`、`false` 保留原义。处理函数参数内部的 JSON `null` 是实际参数，另按资源需求解释。
- 枚举只接受列出的字符串，区分大小写。颜色只接受 `#RRGGBB`、`#RRGGBBAA`，十六进制字母不区分大小写，末两位为透明度。
- 所有显式像素尺寸、内边距、间距、字号、行高、边框和圆角均要求安全整数，最大为 `9007199254740991`；正负范围见各表。透明度和处理函数自有参数不套用整数规则。
- 默认值和自适应计算只服务本次渲染，不回写 JSON，不删改源模块。
- `composition`、`style`、边框和背景对象中的未知字段保留并警告，不参与绘制。文档、模块和放置记录的普通扩展元数据原样保留，不按未知渲染参数警告。
- 明确认出的旧渲染字段保留并警告，不赋予当前语义：旧素材字段、`elements`、`span`、模块自身 `position`、`contentScale`、旧偏移及层级、`rowGap/columnGap`、旧 `processor`。模块中仅适用于其他类型的图片或布局字段也不参与渲染。

## 固定尺寸与空内容

| 参数或情形 | 规则 |
| --- | --- |
| 叶子 `width`、`height` | 必填正安全整数，表示包含边框和内边距的整体尺寸；不接受 `"auto"` |
| 容器 `width`、`height` | 不提供手动尺寸能力；出现时保留并警告，不参与自然布局 |
| 空文字 | `text` 为空或全为空白时忽略整个模块，不占尺寸、边框、内边距或间距 |
| 空容器 | 没有有效子模块时忽略整个容器；从内向外判断 |
| 空根 | 提示“无可渲染内容”，不生成 PNG；仍可编辑和保存 |
| 缺图模块 | 不属于空内容，保留模块尺寸和位置，使用资源需求规定的占位图 |
| 透明或无装饰模块 | 不因透明而忽略，仍保留布局占位 |

忽略只作用于渲染树。原始参数及网格占位仍先接受合法性检查；空内容不使重复位置、越界或非法参数变为合法。

## 网格自然布局

| 参数 | 默认值 | 范围 |
| --- | --- | --- |
| 容器 `padding` | `24px` | 非负安全整数，四边统一 |
| 容器 `gap` | `24px` | 非负安全整数，行列统一，允许 `0` |

- 容器使用文档中已声明的网格，不按子项顺序重新排列。
- 每列宽度取该列有效子模块的最大宽度，每行高度取该行最大高度；嵌套容器作为一个整体参与父网格。
- 完全没有有效子模块的行、列折叠，不保留尺寸或间距；其余行、列保持原顺序。单个空单元格仍留空，不导致整行或整列折叠。
- 坐标合法性始终按原始 `layout` 检查。折叠不改写原始坐标。
- 子模块小于单元格时保持自身尺寸，水平、垂直居中；不拉伸成行高或列宽，也不让各列均分某个固定父宽。

自然尺寸的可观察关系为：

```text
宽 = 有效列宽之和 + (有效列数 - 1) × gap + 2 × padding + 2 × borderWidth
高 = 有效行高之和 + (有效行数 - 1) × gap + 2 × padding + 2 × borderWidth
```

未启用边框时 `borderWidth=0`。空容器不使用此关系；内层容器的内边距和边框已经包含在自身尺寸中，父级不重复增加。

## 最终输出与适配

| 参数 | 默认值 | 合法值 |
| --- | --- | --- |
| `composition.width` | `"auto"` | 正安全整数或 `"auto"` |
| `composition.height` | `"auto"` | 正安全整数或 `"auto"` |

两个方向均自适应时按自然布局出图，不设固定保底宽度。只指定一个方向时，只约束该方向，另一方向按适配后的完整布局计算。显式尺寸必须精确保持，不能为了消除留白或小数改变输出尺寸。

### 根为容器

1. 普通适配只调整根容器的内边距和间距，保持各子模块尺寸；内层容器保留自身配置。横纵方向独立计算实际间距。
2. 指定方向的空间先由有效行列、根边框和根间距共同填满。内边距与间距保持源配置的比例；空间增加时共同增加，不足时共同减小，最小为零。
3. 两项源配置均为零时，间距保持零，多余空间平均分配到两侧内边距。只有一项为零时，该项保持零；若有效行列使另一项没有可分配位置，多余空间同样放入两侧内边距。
4. 指定方向在根内边距和间距均为零时仍放不下，采用不超过 `1` 的最大统一缩小比例，使所有指定方向都能容纳内容和根边框；未指定方向不额外限制比例。
5. 缩小时，全部模块的几何尺寸、非文字内边距、间距、边框和圆角使用同一比例，根边框也包含在内。文字的内容区内边距同样缩小，字号和行高保持原值。之后按相同比例关系分配指定方向的根剩余空间。
6. 自适应方向保留经统一比例缩放后的原始根间距，据最终布局计算尺寸；不为了跟随另一方向而额外拉大。

### 根为叶子

- 输出比模块大时，保留模块尺寸，水平、垂直居中；额外区域透明。模块背景仍只覆盖模块本身，不扩成画布背景。
- 任一指定方向放不下时，使用能同时满足所有指定方向的最大统一比例缩小，比例不超过 `1`；不拉伸、不放大。
- 缩小后的模块在指定方向居中；自适应方向的输出等于缩小后的模块尺寸。图片继续按自己的 `fit` 处理内部内容；文字字号和行高保持原值并重新排版。
- 例如 `320×200` 的根配 `600×600` 输出，模块仍为 `320×200`，左上角为 `(140, 200)`；配 `160×600` 输出，模块为 `160×100`，左上角为 `(0, 250)`。

### 精度与极端尺寸

- 中间计算保留精度，最终布局坐标和尺寸最多保留一位小数，避免逐层取整积累误差；缩放比例不限制为一位小数。
- 自适应得到的最终 PNG 宽高向上取整为整数，显式输出尺寸保持不变。
- 统一缩小必须警告，指出受影响模块、自然尺寸、目标尺寸和实际比例，并建议调整尺寸；不修改源参数。
- 极端缩小和最终舍入使某模块或内容区变为零面积时，该区域不绘制，仍归入缩小警告，不把合法源参数重新判为非法，也不反向撑大布局。
- 不另设固定业务尺寸上限。计算结果不可表示、绘制目标无法创建或实际环境无法支持时必须明确报错，不能静默返回空白或截断结果。

## 文字

| 参数 | 默认值 | 范围或含义 |
| --- | --- | --- |
| `style.fontSize` | `24px` | 正安全整数 |
| `style.lineHeight` | 字号的 `1.2` 倍，默认 `28.8px` | 显式值为正安全整数像素，不是倍率；默认计算值保留一位小数 |
| `style.color` | `#000000` | 规定的十六进制颜色 |
| `style.bold` | `false` | 布尔值 |
| `style.align` | `"left"` | `"left"`、`"center"`、`"right"` |
| `style.verticalAlign` | `"center"` | `"top"`、`"center"`、`"bottom"` |
| `style.wrap` | `true` | 布尔值，控制自动换行 |
| `style.padding` | `0px` | 非负安全整数，文字自身四边统一内边距 |

字体选择及 `style.fontFamily` 的默认值只在资源需求中定义。

- 内容宽高分别为整体宽高减去两倍的内边距与边框之和。源参数扣除后的两个方向必须均大于零，否则报参数冲突，提示调整尺寸、内边距或边框。
- 文字在内容区内排版，字号和行数不改变模块尺寸；水平对齐逐行生效，垂直对齐作用于完整文字块。文字块高度按行数乘行高计算。
- 保留显式换行；`CRLF`、`LF` 和单独 `CR` 均作为换行，末尾换行保留空行。空格不折叠，制表符按四个空格显示；这些显示处理不改写原文。
- 开启自动换行时，按实际字体宽度排版：英文单词保持完整，只在词边界换行；单词在空行也放不下时仍独占一行，超出内容区的部分直接裁剪，不拆分单词。中文允许在完整字素之间断行，不拆开 Emoji 或组合字符。不额外加入连字符、省略号或标点避头尾规则。
- 单个字素超过行宽时仍保留该字素，由内容区裁剪。关闭自动换行时只使用原文换行，不按宽度断行。
- 每行文字在行高区域内垂直居中；实际字形仍按内容区裁剪。文字块超过内容区时沿用所选对齐，不自动改成顶对齐。
- 显式行高小于字号时仍使用原行高，允许文字行相互重叠；不自动增大行高、不报参数错误，也不按单行行框裁掉字形，仅裁剪超出整个内容区的部分。
- 合法内容区中的溢出直接裁剪，不警告、不缩小字号、不添加省略号。整体输出缩小后按最终内容区重新排版，也不为文字裁剪额外警告。

## 图片内容适配

| 参数 | 默认值 | 范围 |
| --- | --- | --- |
| `fit` | `"contain"` | 下表五种取值 |
| `style.align` | `"center"` | `"left"`、`"center"`、`"right"` |
| `style.verticalAlign` | `"center"` | `"top"`、`"center"`、`"bottom"` |
| `style.padding` | `0px` | 非负安全整数，图片自身四边统一内边距 |

| `fit` | 效果 |
| --- | --- |
| `"contain"` | 等比完整显示，比例不同则留空 |
| `"cover"` | 等比铺满，裁剪超出部分 |
| `"stretch"` | 分别适配宽高，允许变形 |
| `"height"` | 等比适配高度，宽度可能留空或超出 |
| `"width"` | 等比适配宽度，高度可能留空或超出 |

图片内容区沿用文字的内边距、边框扣除规则，源参数下宽高必须大于零。正常素材先完成资源文档规定的处理链，再执行 `fit` 和对齐。超出内容区直接裁剪，不警告，不改变模块尺寸；留空区域透出模块背景。

图片和图片背景的最终适配统一采用高质量平滑缩放，首版不增加逐图片的最近邻选项。绘制及 PNG 输出统一使用常规 sRGB 色彩空间，正确转换素材色彩并保留透明通道，不保留原素材的广色域输出或 ICC 配置。

## 外观与背景

| 参数 | 默认值 | 要求 |
| --- | --- | --- |
| `style` | 各项独立默认值 | 配置时必须为对象，不接受样式名称字符串 |
| `style.radius` | `0px` | 非负安全整数；绘制时不超过模块短边的一半，不改写原值 |
| `style.opacity` | `1` | `0～1` 的有限数，可为小数；影响整个模块及子内容，`0` 仍占位 |
| `style.border` | 不绘制 | 配置时必须为对象；空对象启用默认边框 |
| `style.border.width` | 启用时 `1px` | 非负安全整数，`0` 不绘制，实线边框全部位于整体尺寸内 |
| `style.border.color` | 启用时 `#000000` | 规定的十六进制颜色 |
| `style.background` | 透明、不绘制 | 配置时必须为带 `type` 的对象，不接受颜色字符串简写 |

背景对象分为两种：

| `type` | 字段 |
| --- | --- |
| `"color"` | 必填 `color`，遵循颜色规则 |
| `"image"` | 可选 `assetPath`；`fit` 默认 `"cover"`，`align` 和 `verticalAlign` 默认 `"center"`，取值与图片相同 |

- 背景覆盖模块完整区域，包括内边距，不影响自然尺寸。未配置背景时保持透明，子模块可透出父背景，PNG 保留透明通道。
- 不另设画布背景字段；根容器可用自身背景覆盖输出区域。叶子根的额外画布留白仍遵循前述透明规则。
- 绘制关系为背景在底，文字、图片或子模块在其上，边框在最上。所有绘制受模块圆角边界限制，内容另受内容区限制，子内容不能越过所属容器。
- 整体透明度作用于模块合成后的整体，不逐层重复施加；嵌套模块各自的透明度继续生效。
- `rect` 只绘制自身外观，不额外要求图片或文字内容。纯容器可完全不设装饰。
- 图片背景不接收普通图片模块的处理链；当前背景只有纯色和图片，不提供旧背景毛玻璃类型。

## 错误、警告与导出

| 情形 | 处理 | 允许继续出图 |
| --- | --- | --- |
| 缺少必填项，已知参数类型、枚举、颜色或范围错误 | 定位原始字段并说明原因 | 否 |
| 多根、ID 重复、占位重复、越界、非法父子关系 | 定位模块和关系 | 否 |
| 无有效内容 | 提示“无可渲染内容” | 否 |
| 未知或旧渲染字段 | 保留并警告，不执行该字段 | 是 |
| 指定字体不可用 | 警告并使用资源需求中的回退规则 | 是 |
| 图片未选择、不存在、读取或解码失败 | 警告并使用占位图，保留占位和源引用 | 是 |
| 合法内容区中的图文溢出 | 直接裁剪，不警告 | 是 |
| 输出不足导致统一缩小 | 报告尺寸、比例及受影响模块 | 是 |
| 处理函数未注册、参数/执行失败或输出无效 | 报告函数、步骤和原因，停止处理 | 否 |
| 绘图或 PNG 编码能力不足、尺寸不支持、资源已过期 | 明确报错，不返回成功导出 | 否 |

错误和警告都必须具有稳定类别、可读原因及能够取得的模块 ID、原始字段位置；不能只在控制台报告。渲染阻断不禁止继续编辑或保存 JSON。

Engine 返回 Canvas 渲染结果并提供 PNG 数据，不选择路径或写入磁盘。后续调用方默认将整图保存为 JSON 同目录、同名 `.png`，不修改 JSON 路径；已有同名 PNG 由调用方要求用户明确选择覆盖，保存失败不破坏已有文件。输出缩放只改变图像，不保存中间处理图片或覆盖原素材。

## GUI 预览、提示与导出流程

| 情形 | 已确认行为 |
| --- | --- |
| 预览内容 | 使用当前文档已应用的内容；右侧连续输入不自动逐字刷新，点击“应用”后更新 |
| 打开或重新加载文档 | 展示载入文档的预览；没有有效内容时显示空状态或诊断，仍允许编辑 |
| 屏幕显示 | 保持图片比例，自动适应预览区域；窗口大小变化时重新适应，不修改文档的输出尺寸 |
| 放大查看 | 用户通过扩大或最大化窗口获得更大的预览；不提供自由缩放、平移或“100%”按钮 |
| 模块选择 | 预览可用于点击选中模块，右侧单模块详情及选择范围见[GUI 需求](architecture.md#gui-布局与交互边界) |
| 集中问题展示 | 使用简洁状态提示，按需展开错误和警告详情，不默认常驻完整问题列表 |
| 渲染失败 | 提供明确诊断；可以保留上次成功预览，但标记为过期，不能作为当前结果导出 |
| 导出前有未保存修改 | 先按文档及资源需求保存已应用的 JSON 内容和待复制素材，成功后再导出；失败则停止并提示 |
| 未应用输入 | 不参与 PNG 导出，不因为点击导出而隐式应用 |
| 导出位置与重名 | 遵循本节之前定义的同目录、同名 PNG 及覆盖确认规则 |
| 导出结果 | 分别报告文档保存和 PNG 保存的结果；PNG 失败不冒充完整导出成功 |

源图像、已应用编辑状态和预览结果必须保持可对应。保存导致新素材引用从原文件转为副本时，应保持同一已确认素材内容；副本仍是原始素材，不能将已处理的输出当作原图再次执行处理链。PNG 编码继续复用该版本已完成的渲染结果，不另建一套合成流程。

## 验收条件

使用符合当前协议的样例，覆盖单叶子根、嵌套与稀疏网格、空内容折叠、零间距、边框和内容区、五种图片适配、透明背景、圆角和整体透明度、显式换行及中英文/Emoji、溢出裁剪、缺图与字体回退、处理链、单边和双边输出约束、极端缩小及舍入。逐项核对最终尺寸、模块位置、诊断、源数据保持，以及实际 Tauri WebView 中预览和 PNG 的一致性。历史图片处理 PNG 不能代替整图排版验收。

GUI 验收另核对：点击应用才更新属性编辑预览、单模块选择和详情范围、随窗口变化保持比例适应、简洁提示与详细问题展开、过期预览禁止导出，以及先保存成功再导出和同名 PNG 覆盖确认。以上均为待执行的验收条件。
