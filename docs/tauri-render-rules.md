# 图片渲染参数与校验规则速查表

本文汇总第一版已确认的参数、默认值和异常处理约定，供查阅与审阅使用。表中规则不代表对应功能均已完成。

字段路径以所在模块为起点；`composition` 为文档的最终输出配置。像素参数使用安全整数，即绝对值不超过 `9007199254740991` 的整数；具体正负范围按各表规定。

## 通用约定

| 项目 | 规则 | 不符合时的处理 |
| --- | --- | --- |
| 必填参数 | 必须存在且类型正确，不自动猜测 | 报错，阻止渲染 |
| 可选参数 | 省略时使用表中默认值；显式配置优先 | 非法值报错，不用默认值掩盖错误 |
| `null` | 已定义的渲染参数不接受显式 `null`，不能用它表示默认值 | 报错，阻止渲染 |
| `0`、`false` | 参数允许时保留其含义，不按缺省处理 | 按参数自身范围判断 |
| 枚举 | 只接受列出的字符串，区分大小写 | 报错，阻止渲染 |
| 颜色 | 只接受 `#RRGGBB`、`#RRGGBBAA`，十六进制字母不区分大小写，末两位为透明度 | 短十六进制、颜色名称、`rgb()`、`hsl()` 等报错 |
| 未知渲染字段 | 保留原值，不参与渲染 | 警告，允许继续 |
| 扩展元数据 | 文档、模块、放置记录上的普通元数据原样保留，如标题、来源笔记、编辑信息；内部可含 JSON `null` | 不按未知渲染字段警告 |
| 默认值和自适应结果 | 只用于本次渲染，不改写原始 JSON，不自动删除源模块 | 不自动保存计算结果 |
| UI 调节 | 已确认的尺寸、间距、文字、图片与外观参数支持独立调节，使用相同校验规则 | 非法参数不能用于渲染 |

## 文档与模块结构

| 字段或对象 | 缺省规则 | 合法条件与处理 |
| --- | --- | --- |
| `image-create-tool-version` | 必填 | 当前渲染格式为 `"v0.2.0"` |
| `documentId` | 必填 | 非空、非纯空白字符串 |
| `revision` | 必填 | 非负安全整数 |
| `composition` | 必填 | 对象；宽高可分别省略 |
| `modules` | 必填 | 数组，必须且只能有一个根模块；根可以是叶子或容器 |
| 模块 `id` | 必填 | 非空、非纯空白字符串，全文档唯一 |
| 模块 `type` | 必填 | `"text"`、`"image"`、`"rect"`、`"group"` |
| 叶子模块 | `text`、`image`、`rect` | 必须指定宽高；不允许 `layout` 或非空 `children`，允许省略或空 `children` |
| 容器 `children` | 空数组 | 子项为含 `position` 和 `module` 的放置记录；子项顺序不决定网格位置 |
| 放置记录 `module` | 必填 | 实际子模块对象，可以继续嵌套容器 |
| 父子关系 | 通过容器的放置记录表达 | 模块不能循环包含自身或祖先 |
| 空文字、空容器 | 忽略整个模块 | 不占尺寸、内边距、间距；仅渲染时忽略，源数据保留 |
| 根模块无有效内容 | 不生成 PNG | 提示“无可渲染内容”，文档仍可编辑、保存 |

## 尺寸与网格

| 字段或情形 | 缺省规则 | 合法条件与处理 |
| --- | --- | --- |
| 叶子 `width`、`height` | 必填 | 正安全整数；不接受小数或 `"auto"`，表示模块整体宽高 |
| 容器 `width`、`height` | 按内容计算 | 当前不支持手动指定；遇到这些字段保留并警告，不参与布局 |
| 容器 `layout` | 必填 | `[行数, 列数]`，恰好两个整数，每项为 `1～4294967295` |
| 放置记录 `position` | 必填 | `[行, 列]`，恰好两个整数，从 `0` 开始，每项不超过 `4294967295`；必须在父容器网格范围内 |
| 同一容器的占位 | 每个子模块占一个单元格 | 不允许重复坐标；不同容器可以各自使用相同坐标 |
| 容器 `padding` | `24px` | 非负安全整数，四边统一 |
| 容器 `gap` | `24px` | 非负安全整数，行列共用；允许 `0` |
| 列宽、行高 | 按子模块尺寸计算 | 每列取该列子模块最大宽度，每行取该行最大高度；嵌套容器先计算自身尺寸 |
| 完全空的行、列 | 自动折叠 | 保留有效行列的顺序；不为被折叠的行列保留空间或间距，坐标合法性仍按原始网格检查 |
| 单个空单元格 | 允许 | 所在行、列还有其他内容时，不折叠整行、整列 |
| 子模块小于单元格 | 水平、垂直居中 | 保持子模块自身宽高 |
| 容器自然宽度 | 按内容计算 | 各有效列宽之和，加列间距、两侧内边距、两侧边框 |
| 容器自然高度 | 按内容计算 | 各有效行高之和，加行间距、上下内边距、上下边框 |

## 文字

| 字段 | 默认值 | 合法条件与处理 |
| --- | --- | --- |
| `text` | 必填 | 字符串；空字符串或全为空白时忽略整个模块，不修改原文 |
| `style.fontSize` | `24px` | 正安全整数 |
| `style.color` | `#000000` | 六位或八位十六进制颜色 |
| `style.align` | `"left"` | `"left"`、`"center"`、`"right"`；控制文字在自身内容区内的水平对齐 |
| `style.verticalAlign` | `"center"` | `"top"`、`"center"`、`"bottom"` |
| `style.bold` | `false` | 布尔值 |
| `style.lineHeight` | 字号的 `1.2` 倍；默认字号下为 `28.8px` | 显式值为正安全整数像素，不是倍数；默认计算结果可有一位小数 |
| `style.wrap` | `true` | 布尔值；关闭时不自动换行，原文中的显式换行仍保留 |
| `style.padding` | `0px` | 非负安全整数，文字自身的四边统一内边距，与容器内边距独立 |
| `style.fontFamily` | `"sans-serif"` | 非空、非纯空白字符串，可选择本地字体；指定字体不可用时回退默认字体并警告 |

| 情形 | 处理 |
| --- | --- |
| 扣除文字内边距和边框 | 内容宽、高均必须大于 `0`，否则报错并提示调整尺寸、内边距或边框 |
| 内容区计算 | 宽度减去两倍的内边距与边框之和，高度同理 |
| 字号过大、换行增加文字高度 | 模块宽高保持不变，不撑大父布局 |
| 文字超出合法内容区 | 直接裁剪，不警告、不缩小字号 |
| 极端输出适配缩小模块 | 字号和行高保持原值，按缩小后的内容区重新排版并裁剪 |

## 本地图片与处理链

| 字段或情形 | 默认值 | 合法条件与处理 |
| --- | --- | --- |
| `assetPath` | 未选择图片 | 本地路径字符串；相对路径以图片 JSON 所在目录为基准，也允许绝对路径 |
| 路径为空字符串或全为空白 | 未选择图片 | 警告，保留模块尺寸和位置，使用“警告：找不到图片”占位图 |
| 非本地路径 | 不接受 | URI、非字符串、`null`、含 NUL 字符的路径报错；不支持 HTTP、data、file URI |
| 文件不存在、读取失败、解码失败 | 使用警告占位图 | 警告并继续出图，保留模块尺寸和原始引用 |
| 素材来源 | 用户自行准备 | 只读取最终本地图片，不提供素材搜索、下载或别名查询 |
| `fit` | `"contain"` | `"contain"`、`"cover"`、`"stretch"`、`"height"`、`"width"` |
| `style.align` | `"center"` | `"left"`、`"center"`、`"right"`；控制图片在自身内容区内的水平对齐 |
| `style.verticalAlign` | `"center"` | `"top"`、`"center"`、`"bottom"` |
| `style.padding` | `0px` | 非负安全整数，图片自身的四边统一内边距 |
| 图片有效内容区 | 扣除自身内边距及边框 | 宽、高必须均大于 `0`，否则报错 |
| 适配后超出内容区 | 裁剪 | 不警告，不改变模块尺寸 |
| 警告占位图 | 完整、水平垂直居中显示 | 跳过原素材处理链，避免警告被裁剪或模糊 |
| `processors` | 空数组 | 图片处理调用数组，按顺序处理素材，再适配到模块内容区；非图片模块不支持非空处理链 |
| 单次处理调用 | 无隐式补参 | `[函数标识, ...参数]`；标识为非空字符串，参数按顺序保留，由函数规定数量、类型及范围 |
| 处理函数参数 | 遵循各函数约定 | 参数可为任意 JSON 值；其中的 `null` 表示实际参数，不表示使用渲染默认值 |

| `fit` 取值 | 规则 |
| --- | --- |
| `"contain"` | 等比完整显示，比例不同则留空 |
| `"cover"` | 等比铺满，裁剪超出部分 |
| `"stretch"` | 分别适配宽高，允许改变原图比例 |
| `"height"` | 等比适配高度，宽度可能留空或超出 |
| `"width"` | 等比适配宽度，高度可能留空或超出 |

## 模块外观与背景

| 字段或情形 | 默认值 | 合法条件与处理 |
| --- | --- | --- |
| `style` | 使用各项默认值 | 配置时必须为对象，不接受 `null` |
| `style.radius` | `0px` | 非负安全整数；绘制时最多为模块短边的一半，超出时按上限绘制，不改写原值 |
| `style.opacity` | `1` | `0～1` 的有限数值，允许小数；作用于整个模块及其子内容，不改变布局占位 |
| `style.border` | 不绘制边框 | 配置时为对象；空对象表示启用默认边框 |
| `style.border.width` | 启用时 `1px` | 非负安全整数；`0` 不绘制，边框包含在模块整体尺寸内 |
| `style.border.color` | 启用时 `#000000` | 六位或八位十六进制颜色；当前边框为实线 |
| `style.background` | 透明、不绘制背景 | 配置时为带 `type` 的对象，不接受颜色字符串简写 |
| `style.background.type` | 配置背景时必填 | `"color"`、`"image"` |
| `style.background.color` | 纯色背景必填 | 六位或八位十六进制颜色 |
| `style.background.assetPath` | 图片背景未选择素材 | 与普通图片采用相同的本地路径规则；未选择或加载失败时使用警告占位图 |
| `style.background.fit` | 图片背景 `"cover"` | 与普通图片相同的五种适配枚举 |
| `style.background.align` | 图片背景 `"center"` | `"left"`、`"center"`、`"right"` |
| `style.background.verticalAlign` | 图片背景 `"center"` | `"top"`、`"center"`、`"bottom"` |
| 背景所属范围 | 每个模块自身配置 | 子模块可单独设置，通常在根模块设置；不另设画布背景字段 |
| 背景绘制范围 | 模块完整区域，包括内边距 | 不影响内容自然尺寸；图片背景超出部分裁剪 |
| 模块未配置背景 | 保持透明 | 子模块透出父背景，根模块保留 PNG 透明通道；不产生缺图警告 |

## 最终输出与自适应

| 字段或情形 | 默认值或处理规则 | 提示 |
| --- | --- | --- |
| `composition.width`、`composition.height` | 省略即 `"auto"`；显式值为正安全整数或 `"auto"` | 非法值报错 |
| 未指定输出宽高 | 按内容自然尺寸出图，无固定保底宽度 | 展示实际输出尺寸 |
| 仅指定一个输出维度 | 约束该方向，另一方向按最终布局自适应 | 展示实际输出尺寸 |
| 输出尺寸的业务上限 | 不另设固定上限；实际绘制目标不支持或无法创建时停止出图 | 报错并说明尺寸无法支持 |
| 指定尺寸大于自然内容 | 优先增加根容器的内边距和间距，保持子模块原始尺寸 | 正常适配 |
| 间距分配比例 | 根容器的内边距和间距按配置比例共同调整，横纵方向分别计算 | 不改写源参数 |
| 内边距与间距同时为 `0` | 间距保持 `0`，多余空间平均放入两侧内边距，内容整体居中 | 正常适配 |
| 普通间距适配的范围 | 只调整根容器，内部容器保持各自的内边距和间距 | 正常适配 |
| 指定尺寸不足 | 先缩小根容器的内边距和元素间距，降至 `0` 仍不足时统一等比缩小模块 | 统一缩小时警告 |
| 统一缩小的几何规则 | 使用同一比例，保持各模块宽高比及相对大小；内边距、边框和圆角随之缩小 | 说明受影响模块、自然尺寸、目标尺寸及比例，建议调整尺寸 |
| 统一缩小时的文字 | 字号、行高不缩小，按最终内容区排版并裁剪 | 不因文字裁剪额外警告 |
| 计算后的像素位置与尺寸 | 最终最多保留一位小数，中间计算保留精度 | 不改写 JSON，不将缩放系数限制为一位小数 |
| PNG 最终宽高 | 自适应结果有小数时向上取整；显式指定的整数保持不变 | 展示最终整数尺寸 |

## 错误、警告与兼容处理

| 情形 | 处理 | 是否允许继续出图 |
| --- | --- | --- |
| 已知参数类型、范围、枚举错误，或缺少必填项 | 报告具体字段路径和原因 | 否 |
| 多根、ID 重复、坐标重复、网格越界、非法父子结构 | 报告具体字段路径和原因 | 否 |
| 无有效内容 | 提示“无可渲染内容”，保留可编辑、可保存的源文档 | 否 |
| 未知渲染参数 | 保留原值，警告，该字段不参与渲染 | 是 |
| 旧素材字段 `assetId`、`assetQuery`、`assetsDir`、`assetAliases` | 保留并警告，不搜索或猜测素材位置 | 是，缺图另按占位规则处理 |
| 旧 `elements`、`span`、`rowGap`、`columnGap` 等未支持字段 | 保留并警告，不自动转换或赋予渲染含义 | 是，其他有效参数仍须满足要求 |
| 指定字体不可用 | 回退系统默认字体并警告 | 是 |
| 图片未选择或无法加载 | 使用警告占位图，保留模块占位 | 是 |
| 合法内容区中的文字或图片溢出 | 裁剪，不警告 | 是 |
| 因输出尺寸不足统一缩小 | 警告并建议用户调整尺寸 | 是 |
| 处理函数未注册、执行失败或输出无效 | 报告函数标识及步骤 | 否 |
| 绘制目标尺寸不支持或无法创建 | 报错 | 否 |

历史 JSON 不自动迁移；字体缺字策略和历史数据迁移方式留待后续单独确定。
